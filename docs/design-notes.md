# 设计笔记

记录架构决策、待实现部分和调试过程。给未来的自己（也顺便当作实验报告素材）。

## 1. 为什么全部用硬件逻辑做

课程要求是"数字系统设计"，所以刻意没有用 Nios II 软核 + C 代码播放音频这条路。整条链路全部是
可综合的 Verilog：

- 不依赖任何 IP 核，`quartus_sh --flow compile` 一条命令就能出 sof；
- 每个模块职责单一，方便后续替换（比如把 `beep` 换成 I2S/DAC 输出音质会好很多）；
- 时序逻辑里没有除法器和浮点，资源占用很小。

## 2. 模块接口约定

### `songData`

| 端口 | 方向 | 位宽 | 说明 |
| --- | --- | --- | --- |
| `clk` | in | 1 | 50 MHz |
| `enable` | in | 1 | 播放使能，高有效 |
| `resetIdx` | in | 1 | 低有效复位：指针归零，从头播放 |
| `tone` | out | 26 | 当前音符的时钟周期数（0 = 休止/静音） |
| `toneTime` | out | 5 | 时值编码 1/2/4/8/16 |
| `bpm` | out | 8 | 当前速度（常量 64） |
| `finish` | out | 1 | 整首播完拉高 |

### `beep`

| 端口 | 方向 | 位宽 | 说明 |
| --- | --- | --- | --- |
| `clk` | in | 1 | 50 MHz |
| `rst_n` | in | 1 | 低有效复位 |
| `en` | in | 1 | 输出使能，0 时计数器保持不变 |
| `FREQ_T` | in | 26 | 半周期对应的时钟数 |
| `pwm` | out | 1 | 50% 占空比方波 |

### `rgbRenderer`（尚未接入顶层）

WS2812 8×8 点阵驱动，思路是**双缓冲 + 写标志翻转**：

1. 上层改写 `x / y / pixelToWrite`；
2. 翻转 `write_flag`，模块检测到边沿后写入 `write_buf`；
3. 一个刷新周期（64 像素发完 + 复位间隔）结束后，`write_buf` 整体拷进 `disp_buf`。

这样刷新过程中画面不会撕裂。时序参数按 50 MHz 换算：`T0H=15`、`T1H=35`、`T0L=40`、`T1L=15`。

## 3. 游戏状态机（设计稿）

`gameController.v` 里目前只有伪代码，规划如下：

```
IDLE ──按键──► ENTER_GAME ──► LOAD ──► PLAYING ──finish──► FINISHED ──► IDLE
                 │             │          │                     │
                 └ 主菜单循环   └ 查曲库    ├ 音符下落刷新点阵     └ 数码管显示分数
                              选曲         ├ 按键判定 + 计分       点阵播放结算动画
                                           └ 进度 LED 分段点亮
```

需要补的接口：

- 从 `songData` 额外引出 `idx` 和 `length`（现在是内部信号），供进度 LED 和结算使用；
- 一个统一的按键消抖模块（20 ms 计数），四个功能键共用；
- 判定逻辑：在音符命中的时间窗口内比较按键值与当前音高，命中加分、错过清零连击。

## 4. 调试记录

### 4.1 换音时的"尖音"

现象：单音持续时正常，音符切换的瞬间能听到一声很细的啸叫/爆音。

原因分析：`beep.v` 里相位计数器与音高是异步的——

```verilog
if(cnt >= FREQ_T - 26'd1) cnt <= 0;
```

如果上一个音符是低音（`FREQ_T` 大，计数器已走到很大），切到高音（`FREQ_T` 小）时条件立刻成立，
计数器被提前清零，占空比比较器 `cnt <= FREQ_T/2` 在那一拍输出一个宽度只有几个时钟的"残缺高电平"。
几十纳秒的窄脉冲 = 频谱很宽 = 听感上就是尖锐的"叽"。

修法（待实施）：

```verilog
reg [25:0] freq_d;
always @(posedge clk or negedge rst_n)
    if(!rst_n) freq_d <= 26'd0;
    else       freq_d <= FREQ_T;

wire freq_changed = (FREQ_T != freq_d);

// 计数器中：音高变化时清零相位，从完整周期开始
if(freq_changed) cnt <= 26'd0;
else if(cnt >= FREQ_T - 26'd1) cnt <= 26'd0;
else cnt <= cnt + 1'b1;
```

进阶：再加一个 8 位幅度包络（每个音符开始 5 ms 内占空比从 0 线性升到 50%，结束前再降下来），
爆音基本可以完全消掉。
